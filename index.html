개인정보 처리방침

최종 업데이트: 2026년 5월 5일

1. 수집하는 정보

MindTrade는 거래 기록, 감정 점수, 편향 태그 등 사용자가 직접 입력하는 데이터를 수집합니다. 모든 데이터는 기기 내에 저장되며 외부 서버로 전송되지 않습니다.

2. 데이터 저장 및 보안

데이터는 기기의 로컬 저장소(SwiftData)에 저장됩니다. iCloud 백업 기능을 사용하는 경우, 사용자의 iCloud 계정에 암호화된 형태로 저장됩니다.

3. 인앱 구매

프리미엄 구독은 RevenueCat을 통해 처리됩니다. 결제 정보는 Apple이 관리하며, 앱은 결제 정보에 직접 접근하지 않습니다.

4. 제3자 공유

수집한 데이터를 제3자에게 판매하거나 공유하지 않습니다.
